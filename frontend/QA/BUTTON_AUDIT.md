# HM Academy Button Audit

## Goal
Ensure preview users only see actions that work.

## Audit targets
- Navigation buttons
- Course actions
- Lesson actions
- Audio/video controls
- Assessment actions
- Settings actions

## Rules
- Working actions remain visible.
- Unfinished actions should be disabled or marked as coming soon.
- Every active button must have a clear destination or handler.

## Status
Audit checklist created. Implementation follows after locating each interactive element.
