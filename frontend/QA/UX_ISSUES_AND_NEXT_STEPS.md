# HM Academy UX Issues and Next Steps

## Reported UX Issues

1. Clicking the HM Academy brand should return to the home page, but currently it feels like a highlight/selection only.
2. The student registration data entry path is not clearly exposed.
3. Lesson audio buttons appear present, but the audio files or playback wiring do not work reliably.
4. Some buttons are active while others are inert, which creates confusion.
5. Media sections currently have little or no content to try.
6. Settings navigation opens the page, but the options are not interactive.
7. The current visual style feels too flat and dry; the palette needs warmer, more modern contrast.

## Next Steps
- Convert brand click to a real home navigation link.
- Add a visible student sign-up / profile entry point.
- Wire lesson audio assets and playback handlers.
- Disable or hide inactive buttons until they are functional.
- Add sample media assets for testing.
- Make settings controls functional.
- Refresh the visual design system with a richer palette.
