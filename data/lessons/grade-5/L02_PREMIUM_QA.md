# Grade 5 — Lesson 2 Premium QA

Lesson: `g5-t1-l02` — Les déterminants

## Release gates
- Vocabulary images are real lesson assets and are not replaced by icon fallbacks.
- Every vocabulary card exposes word + meaning + example + two independent speech actions.
- Speech uses the platform speech runtime when available and a fr-FR Web Speech fallback.
- Game Center is lesson-scoped to L02 and has independent state per game.
- Game answers are locked after checking; only one option can be selected before checking.
- Correct answers are highlighted and incorrect selections are marked without changing the answer key.
- Game restart resets score, question index, selection, and feedback.
- Assessment remains separately routed to `grade5-assessment-l02.html`.
- No L01 game-bank dependency is used by the L02 Game Center.
