# HM Academy — Premium Lesson Standard

هذا هو المعيار الإلزامي لأي درس جديد في المنصة من الآن.

## قاعدة العرض
- صفحة درس واحدة متكاملة؛ ممنوع iframe أو صفحة درس داخل صفحة درس.
- جميع الموارد الأساسية تفتح داخل نفس تجربة الدرس: الشرح التفاعلي، المرجع، التقييم، الألعاب، وملفات الدرس.
- لا يكفي وضع كلمة Premium كوسم؛ Premium يعني تجربة تعليمية كاملة وفعالة.

## الحد الأدنى لكل درس
1. عنوان الدرس والوحدة والمرحلة والترم.
2. أهداف تعلم واضحة وقابلة للملاحظة.
3. خريطة رحلة الدرس: شرح → مفردات → قاعدة → تطبيق → تقييم → لعبة → إتقان.
4. جميع المفردات الأساسية، مع معنى عربي واضح.
5. عنصر بصري دال على معنى كل مفردة؛ ممنوع استخدام صورة/رمز عشوائي لا يطابق الكلمة.
6. نطق فرنسي قابل للتشغيل بالضغط على الكلمة/الصورة.
7. وضع تشغيل جماعي للمفردات مع فواصل تسمح بالتكرار.
8. شرح القواعد والأمثلة والتطبيقات.
9. تدريب فوري مع تغذية راجعة.
10. مرجع مستقل كامل داخل نفس الصفحة.
11. تقييم مستقل لا يغيّر إكمال الدرس تلقائياً.
12. ألعاب تعليمية حقيقية مرتبطة بمحتوى الدرس.
13. حفظ التقدم وإكمال الدرس وXP.
14. تصميم responsive ممتاز للهاتف والتابلت والكمبيوتر.
15. دعم العربية والفرنسية والإنجليزية في بنية العرض دون كسر المحتوى.

## أفكار Premium إضافية
- مشهد تفاعلي يربط الصورة بالكلمة والصوت.
- مختبر نطق.
- تحدي الدقيقة.
- لعبة مطابقة الكلمة بالمعنى.
- استماع واختر.
- كبسولة الإتقان: استدعاء + تقليد + إنتاج + تحدي.
- مؤشرات تقدم واضحة وتغذية راجعة غير مزعجة.

## ممنوعات
- صور غير مرتبطة بالمفردة.
- صفحات متداخلة أو iframe للمحتوى الأساسي.
- أزرار تفتح موارد فارغة أو عامة.
- بطاقات كثيرة بلا قيمة تفاعلية.
- تكرار كلمة Premium لإيهام المستخدم بجودة غير موجودة.
- تغيير محتوى المنهج أو حذف درس بسبب تحسين الواجهة.

## التوسع
هذا المعيار هو renderer contract للصفوف والمراحل القادمة؛ يجب أن يكون المحتوى data-driven حتى يمكن تطبيق نفس التجربة على كل المناهج دون نسخ واجهات مختلفة لكل مرحلة.
