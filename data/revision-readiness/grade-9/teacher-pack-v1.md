# HM Academy — Grade 9 Annual Revision — Teacher Pack v1

## Administration
- Give the diagnostic closed-book.
- Record domain-level errors, not only total score.
- Route learners using `remediation-routing-v1.json`.
- Require the checkpoint after each assigned micro-review.
- Use the final assessment only after remediation is complete.

## Checkpoint protocol
A learner passes a checkpoint at 70% or above plus one successful transfer item. If unsuccessful, reteach the micro-review and retest with a parallel item.

## Final decision
- 80–100% + no critical domain below 60%: Strong Ready
- 70–79% + no critical domain below 55%: Ready
- 60–69% or a critical domain below threshold: Targeted Revision
- <60%: Foundation Required

## Writing scoring
Use `teacher-rubric-v1.md`. Do not penalize a learner for an equivalent correct phrase when the target communication function and core structure are accurate.

## Teacher note
The pack is an annual prerequisite review. Do not remove the second-semester domains merely because the current platform lesson import is term-scoped.
