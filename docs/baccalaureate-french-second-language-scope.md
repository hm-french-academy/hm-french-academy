# HM Academy — Egyptian Baccalaureate French L2 Scope

## Target
- Track: Egyptian Baccalaureate
- Subject: French — Second Foreign Language (اللغة الفرنسية لغة ثانية)
- Grade 1: Baccalaureate 1 / أولى بكالوريا
- Grade 2: Baccalaureate 2 / تانية بكالوريا
- Academic cycle: 2026/2027 curriculum release

## Explicit exclusion
This work is NOT for the general secondary first/second grades and NOT for French as a first foreign language. Existing general-secondary or other-grade lesson pages, registries, manifests, routes and content must remain untouched.

## Curriculum evidence
- Ministry policy confirms that the second foreign language is a pass/fail subject for first-year students in the general/baccalaureate system and is taught across the academic year.
- Current 2027 Baccalaureate publishing index identifies French L2 as a subject in the Arts & Humanities track and lists first and second parts for Baccalaureate 2.
- Current web evidence reports the French L2 Baccalaureate 2 student book as two parts totaling 282 pages, with official Ministry-library links.

## Build principle
Use the most stable existing HM Academy lesson/Learning Studio template as a structural reference only. Create isolated Baccalaureate 1/2 identifiers, registries, manifests, routes and lesson data. Do not copy grade-specific IDs or paths from other stages.

## Content workflow
1. Locate official Ministry/official e-library source files.
2. Extract the complete table of contents and lesson sequence for Baccalaureate 1 and 2 French L2.
3. Map each lesson to vocabulary, communication functions, grammar, phonetics/pronunciation, texts/dialogues, activities and assessments.
4. Build HM Academy lesson data and runtime manifests.
5. Preserve the existing Learning Studio UX and smart-review experience.
6. Run route, registry, manifest and cross-grade isolation QA.
7. Scientific/content review remains open for user approval before final release.
