# HM Academy 🇫🇷

## Grade 5 Premium Release

The Grade 5 primary French curriculum is maintained as a Premium Lesson Studio release.

### Release gates
- 11 lessons registered in the Grade 5 curriculum.
- 11/11 lesson videos registered as ready.
- Vocabulary, grammar, pronunciation and practice content are required per lesson.
- Six game modes are required: vocabulary, subject, verb, complement, order and build.
- Lesson Studio runtime is pinned to the current Grade 5 release build.
- Four-part lesson package schema is registered: interactive, printable reference, evaluation and electronic exam.
- Final exam registration is required.
- Automated Grade 5 Release QA runs on pushes to `main` affecting Grade 5 assets and can also be dispatched manually.

See `.github/workflows/grade5-release-qa.yml` and `scripts/grade5-release-qa.mjs` for the release gates.
